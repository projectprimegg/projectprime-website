# Project Prime Website

Official website for Project Prime.

## Current foundation

- Next.js App Router
- TypeScript
- Responsive Project Prime visual shell
- Home, Game, Download, Community
- Coming Soon pages for Maps, Hunters, Leaderboards, and Watch

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Production

The intended deployment target is Vercel, with projectprime.gg connected after the initial deployment is verified.

## Next integration points

- Real Project Prime client download URL
- Official Discord invite URL
